## 익숙한 키보드 선택

| 키 | 동작 |
| --- | --- |
| 방향키 | 화면 방향의 다음 점 한 개 선택 |
| Ctrl+방향키 | 같은 화면 행·열의 끝 점으로 이동·선택 |
| Shift+방향키 | 기준점부터 현재 점까지 사각 범위 선택. 반대 방향은 범위를 줄인다. |
| Ctrl+Shift+방향키 | 기준점부터 행·열 끝까지 사각 범위 선택 |
| Space / Esc | 동작 메뉴 열기 / 닫기 |
| Alt+방향키 | 화면 보기 이동 |

필터에서 숨긴 점·Masking·미사용 Cell은 키보드 작업 선택에서 제외한다. 끝에서 다른 행으로 감기지 않는다. 마우스나 필터·작업 기준을 바꾸면 새 선택 기준점을 사용한다. 방향키는 화면의 선택만 바꾸고 장비를 움직이지 않는다. 메뉴가 열려 있을 때 방향키는 메뉴를 조작한다.

전체 Cell의 마우스 클릭은 해당 Cell 진입, 드래그는 점 다중 선택을 유지한다. 단일 Cell의 Ctrl+클릭·Ctrl+드래그도 유지한다.

## Cell 번호 상시 표시

Cell 번호를 화면 크기의 라벨로 그려 축소해도 읽을 수 있게 했다. 라벨이 겹치면 위치를 조정하고 연결선으로 실제 Cell을 가리킨다. 실제 Cell 위치·회전·배치는 바꾸지 않는다. 라벨 클릭으로 해당 Cell에 들어갈 수 있으며, 미사용 Cell도 번호와 상태를 표시한다.

## 대표 지정과 값 복사는 별개

**존재하는 모든 점을 대표로 지정할 수 있다.** 검증 전·NG·복사된 점·기존 보정·오류·미측정·초기화·Masking도 지정 가능하다. 미저장 Offset 편집 중에도 대표 표시를 바꿀 수 있다. 같은 작업의 상태·출처가 바뀌어도 지정점을 자동 삭제하지 않고, 모델·Run·좌표계가 바뀌면 이전 지정을 해제한다.

| 대표점의 데이터 | 복사하는 값·상태 |
| --- | --- |
| 유효한 새 측정 | 현재 B + 측정 편차. 이미 사용한 측정은 다시 더하지 않는다. |
| 실제 저장된 보정 B | 해당 모델·Shot에서 읽은 B. 빈 기본값 0을 저장 근거로 삼지 않는다. |
| 복사된 값 | 복사 시점에 보관한 최종 F와 원래 출처·판정을 사용한다. |
| 값 없음·초기화·불완전한 값 | 대표 표시는 유지하고 복사할 값이 없다고 표시한다. |

대표 지정이 원측정이나 OK 판정을 만들어내지는 않는다. NG는 NG로, 판정 없음은 그대로 복사한다. 보정 저장은 기존 유효 OK 편차·출처·단위·한계·Scanner Field 검사를 유지한다. 저장 B만 있고 실측 편차 쌍·판정이 없는 복사값은 실제 선택점/일괄 보정 대상이 되지 않는다. 좌표 기준이 맞지 않는 미채택 파일값을 유효 측정으로 바꾸지 않는다. 현재 모델에서 새 측정하는 기능은 유지한다.

Masking 점은 대표 지정용 포커스만 줄 수 있다. 이를 측정·가공 대상에 추가하지 않는다. 미배정 Head의 legacy SCANNER 값은 다른 Head로 임의 환산한 수치를 대표 근거로 쓰지 않는다.

원본 의존 관계는 하나의 Root로 정리하고 복사 시점의 F·판정·출처·기준 Revision을 함께 보관한다. `CopiedFromKey`는 과거의 바로 전 복사 위치를 설명하며 현재 값 계산을 위해 재귀적으로 따라가는 경로가 아니다. 실제 Root 의존 순환은 차단하고, A→B→C 후 C→B처럼 동결값을 다시 복사하는 이력은 중복 가산 없이 처리한다. 값·판정·시점의 부분 변경을 검사하는 checksum은 인증 서명이 아니다.

## 다른 메뉴와의 연결

측정 누적 보정 파일은 기존 Cell/Shot·DESIGN mm 형식을 사용한다. Manual 내부 계산의 DESIGN µm와 파일 mm, Scanner 좌표를 구분한다. 같은 Shot의 Beam은 저장된 보정값을 공유한다.

Recipe·Monitor·Correction의 최신 Review Offset 읽기와 표시, Init/Undo/Redo, 원측정·파일 출처·적용 이력을 회귀검사했다. Recipe 편집/저장 원본·다른 모델의 B·Review 카메라 목표 좌표에 보정값을 다시 더하지 않는다. 하드웨어·Default·First Beam·Distortion과 기존 좌표 수식·writer는 변경하지 않았다.
