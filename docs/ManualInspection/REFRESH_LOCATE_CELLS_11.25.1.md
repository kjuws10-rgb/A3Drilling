# Manual Inspection · 11.25.1

11.25.0 `0d342edcb105ab5fd007dc3a273df52b2099940b` 기준 후속이다. 브랜치는 `feature/manual-inspection-refresh-scope-20261125.1`이며 master에 병합하지 않는다.

## 불필요한 최근 결과 재조회 제거

현 위치 측정값은 응답을 받는 즉시 화면에 반영한다. 이전에는 공식 측정 CSV가 저장되면 파일 감시기가 다시 전체 결과 조회를 요청하고, 명령 종료가 그 작업까지 기다렸다. 전체 조회는 모든 모델의 결과 파일을 조사한 후 현재 모델·기판의 결과를 읽고 좌표 계획과 작업 상태를 재구성하는 작업이다.

이제 파일 감시 알림은 변경 표시만 보관한다. 현 위치 측정·이동·입력·복사·설정·보정 저장이 끝난 뒤 전체 결과 재조회를 자동으로 붙이지 않는다. 외부 파일을 삭제하거나 자체 결과라고 추측해 버리는 방식은 아니다.

| 경우 | 확인하는 내용 |
| --- | --- |
| 현 위치 측정·이동·복사·수동 입력 | Recipe·기판 회차·좌표·실제/SIM·최종 Offset SHA 검사 유지. 전체 결과 검색은 추가하지 않음 |
| 파일 감시 알림 | 변경 여부만 보관. 동작 중에도 전체 결과·최종 보정 전수 조회를 시작하지 않음 |
| 화면 재진입 | 변경 알림이 없으면 현재 기준만 검사. 실제 변경·대기 결과가 있을 때 전체 결과 갱신 |
| 최초 로딩·명시 새로고침·다른 Review 완료 알림 | 필요한 전체 결과 연결 유지. 동작 중 알림은 유예 |
| 보정 저장·Init·Undo/Redo | 저장 후 최종 CSV 재확인 유지 |
| 최종 CSV 조회 실패 후 재진입 | 실패한 최종 보정 조회만 재시도. 전체 결과 검색은 불필요하게 반복하지 않음 |

외부 프로그램이 CSV를 바꾼 경우 열린 화면을 즉시 전수 갱신하지 않는다. **Manual 화면 재진입 또는 새로고침**에서 반영한다. 변경은 로딩 시작 시점까지만 소비하므로 로딩 도중 새로 들어온 알림도 남는다. 실행 직전 실제 기준 검사와 stale 저장 차단은 생략하지 않는다.

## 현 위치 찾기

**현 위치 측정 옆의 ‘현 위치 찾기’**는 현재 정지 위치를 새로 읽어 일치하는 측정 포인트를 지도에 보여준다. 이전 측정점이나 가장 가까운 점으로 추측하지 않는다.

- 일치하면 해당 Cell을 열고 포인트가 보이도록 표시하며, **0.5초 간격으로 4초간** 강조한다.
- 현재 위치에 일치하는 포인트가 없거나 여러 좌표가 겹쳐 구분할 수 없으면 안내한다.
- 설비 이동·Vision 측정·보정 저장은 하지 않는다. 실제 위치 읽기에 시간이 필요하면 진행 표시를 보여준다.
- 기존 측정 중 점멸·NG 빨강·테마·확대/선택 조작은 유지한다.

위치 일치는 기존 도착 판정과 같은 X/Y 각각 ±0.0005 mm를 사용한다. 이는 프로그램의 위치 판정 허용값이며 물리 설비 정밀도 보증이 아니다. 실제 장치 통신은 현장 확인 대상이다.

## 측정 편차와 저장된 최종값 구분

우측 선택점 정보에는 **측정 편차 ΔX/Y**와 **최종 저장 Review 보정 F X/Y**를 함께 DESIGN µm로 표시한다. 최종값은 실제 저장 CSV를 재확인한 자료에서만 읽고, 미저장 후보나 측정값을 저장값처럼 대신 표시하지 않는다. 기존 저장값은 미저장 작업과 구분해 유지하고, 초기화·저장행 없음은 값 없음, 최종 조회 실패는 확인 불가로 표시한다. **지도 색상·Level은 사용자 최종 요청에 따라 기존 측정 편차 기준을 유지**한다.

Monitor의 `REVIEW OFFSET` 행은 현재 선택한 좌표계의 **mm 단위 적용 기여분**이다. 저장 F에 Head 축변환·주행방향·Review Scale을 적용하므로 우측의 DESIGN µm 숫자와 그대로 비교하면 다를 수 있다. Monitor의 ‘저장 DESIGN µm’와 우측 최종 저장 F가 같은 모델·Cell/Shot·CSV SHA에서 직접 비교할 값이다.

예를 들어 Init 후 측정 편차가 X 1.234 / Y -2.346 µm이면 첫 저장 F도 1.234 / -2.346 µm다. Monitor를 DESIGN·Scale 100%로 보면 0.001234 / -0.002346 mm이고, 50%라면 적용 기여분만 절반이다. 저장 F 자체와 측정 원문은 Scale로 바꾸지 않는다. 같은 기준에서도 일치하지 않는 경우만 별도의 갱신 오류로 판단한다.

## 전체 Cell 보기의 일괄 보정

전체 Cell 화면에서는 **선택한 포인트들이 속한 Cell들**이 일괄 보정 대상이다. 선택 Cell 안의 보정 가능한 전체 측정 위치를 검사하며, 선택하지 않은 Cell은 포함하지 않는다. 선택이 없으면 실행하지 않는다. 단일 Cell 화면에서는 기존처럼 현재 Cell 전체가 대상이다.

확인창에서 Cell 목록과 범위를 다시 확인한다. 여러 Cell도 **하나의 후보 → CSV 한 번 저장 → Undo 한 단계**로 처리한다. 기존 Review Offset에 이번 유효 편차를 반영하며, NG·미측정·한계 초과·중복 적용 방지는 유지한다. 미저장 통합 파일 편집은 해당 Cell 하나만 저장할 수 있고 다른 Cell로 범위를 확대하지 않는다.

## 검증 범위

실제 Core·Controller·CSV parser/writer와 별도 WPF 화면을 합성 자료로 검사한다. 파일 감시기의 지연 알림, 명령 중 알림, 최종 보정 재확인 실패 복구, fresh 위치 응답과 최근점 fallback 금지, 선택 Cell 범위·한 Undo·저장 실패를 구분한다. 실제 설비 App/Root/CManager·PLC/Vision/실축·벤더 API·AeroScript 실행·레이저는 실행하지 않는다.

최종 Release는 경고 0·오류 0이다. Core 300, 실제 DLL Controller 318, Backend/CSV/Monitor 194, 가정한 보정 폐루프 21, 이전 직렬화 호환 37, 변경 범위 39, WPF 21개 모드 1,145개 검사를 통과했다. 소스 연결 Controller 315개는 실제 DLL 검사와 중복 합산하지 않는다. 현재 위치 읽기의 Native 장치 통신·실기 정밀도는 위 결과에 포함하지 않는다.
