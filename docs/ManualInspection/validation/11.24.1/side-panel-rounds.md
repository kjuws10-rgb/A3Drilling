# 11.24.1 좌우 패널 검토·구현·검증

## Round 1 — 배치와 기존 연결 검토

- 기준: `feature/manual-inspection-firstload-panels-20261124.1`, 기준 Commit `301ff17`.
- 기존 화면의 이름·이벤트 연결과 View의 펼침/북마크/화면 크기 계산 경로를 읽고, codebehind 담당과 새 패널 이름과 탭 index를 합의했다.
- 왼쪽은 필터·범례·정보·산포·설정·이력, 오른쪽은 항상 보이는 선택점 요약과 상세·대표 복사·보정으로 나눈다. 중앙 지도와 하단 접이식 측정 표를 유지한다.
- 산포 그래프/통계/축/대상, 측정 설정/한계/Level, 보정 실행/초기화/후보는 작은 내부 페이지로 나눠 필수 항목을 접근할 수 있게 한다.
- 기존 모든 named control을 보존했다. 최종 XML에서 원래 이름 누락 0개이며, 이름 공간별 ControlTemplate 이름을 제외한 일반 컨트롤 중복을 만들지 않았다.

## Round 2 — 실제 WPF 소스 연결 시험과 시각 검토

- 기존 Light/Dark 색상 자원을 그대로 사용한 로컬 탭 스타일을 추가했다. 전역 테마나 다른 메뉴는 변경하지 않았다.
- 외부 좌우 패널과 지도 작업공간은 스크롤 없이 유지한다. 적용 이력은 기존 최신 8개의 원문을 보존한 한 줄 말줄임/전체 툴팁으로 표시한다.
- 표시 크기별 양쪽 펼침 상태의 지도 실측:

| 화면 DIP | 지도 DIP | 지도·좌우 외부 스크롤 |
| --- | --- | --- |
| 1120×560 | 533×448 | 없음 |
| 1490×900 | 863×769 | 없음 |
| 1120×720 / 125% 상당 공간 | 533×608 | 없음 |
| 993×600 / 150% 상당 공간 | 406×488 | 없음 |

- 모든 필터 입력과 필터 초기화 버튼은 실제 NG/검색 필터가 켜져 공통 안내가 추가된 경우에도 접근 가능했다.
- 실제 동적 Level 편집기의 7개 입력과 마지막 적용 버튼, 대표 복사와 보정 동작, 초기화 범위, 산포 축 설정이 네 크기에서 잘리지 않는지 확인했다.
- 하단 측정 표를 펼쳐도 중앙 작업공간 전체를 스크롤하지 않는다. 실제 표/대량 통계·대상 데이터의 국소 뷰어는 기존 데이터 접근을 보존한다.
- 빈 첫 모델의 대표 상태 복사, 보정 대상이 없을 때 일괄 보정 설명만 표시하고 backend/동작 요청을 보내지 않는 경계, Offset Init 활성 상태를 검증했다.
- 파일 작업 복귀는 좌우 펼침 상태와 내부 탭들을 실제로 다른 상태로 바꾼 다음 모두 복원되는지 시험했다.
- Dark/Light, 좌측 산포·우측 보정, 실제 Level 편집기 PNG를 직접 열어 확인했다.

## Round 3 — 상호 검토 반영과 최종 동결

- 독립 검토자가 지적한 이력 뷰어의 높이 제약을 유한한 Grid로 정리했다. 최종 사용자 요청에 따라 이력 자체도 최신 8개 한 줄/툴팁으로 스크롤 없이 맞췄다.
- 실제 Level 편집기를 생성한 뒤 마지막 저장 버튼까지 보이는 시험을 추가했다.
- 확대/축소 버튼의 기존 접근성 이름을 보존했다. 빈 대표 상태 복사도 포함하므로 안내를 ‘값 또는 빈 상태 복사, 실제 보정은 별도 검증’으로 맞췄다.
- 최종 소스 연결 UI 빌드: **경고 0, 오류 0**. `--side-panels`: **96/96 통과**. `git diff --check`: 통과.
- 독립 검토자 `/root/bulk_history_qa_1123`가 최종 동결 XAML/시험 SHA와 실제 PNG를 확인했다. 기존 이름 누락·신규 중복·이벤트, 이력 원문 툴팁, 실제 Level 저장 버튼, 좌우 북마크·활성 필터 안내 경계를 검토한 결과 **담당 UI 범위에서 확정 미해결 결함 없음**으로 회신했다. Core/Controller 상태 복사 검증은 이 UI 판정과 별도로 통합 담당이 진행한다.
- 생산 코드 편집은 담당 XAML에 한정했다. 시험 파일은 새 `SidePanelsCases.cs`만 작성했으며 기존 시험/Program/csproj와 codebehind 변경은 통합 담당이 수행했다.
