## 최초 로딩 후 대표값과 버튼

1. 원하는 점을 선택하고 **대표값으로 지정**한다.
2. 다른 대상들을 Ctrl+클릭 또는 드래그로 선택한다.
3. **같은 오프셋·상태 적용**을 누른다.

유효한 대표값이 있으면 기존처럼 값과 판정을 복사한다. 대표점이 초기화·미측정·값 없는 오류 상태라면 **그 빈 측정 상태를 작업 화면에 복사**한다. 측정한 0이나 OK를 새로 만들지 않는다. ‘기존 모델에 저장된 Review Offset B’와 ‘화면의 작업 측정 상태’는 구분한다.

| 대표점 | 작업 화면에 복사하는 내용 | 실제 모델 보정 |
| --- | --- | --- |
| 출처가 확인된 유한 보정값 | 대표값과 판정 | 별도 계산·검증·저장 필요 |
| 초기화·미측정·값 없는 오류 | 값 없음 및 해당 상태 | 현재 저장 B 유지, 실제 보정 대상에서 제외 |
| 실제로 측정한 0 | 유효한 0과 실제 판정 | 기존 검증 조건을 만족하면 사용 가능 |

빈 상태를 복사해도 대상의 원측정·기존 저장 보정·파일은 삭제하지 않는다. **복사 되돌리기**로 작업 상태를 복원할 수 있다. 기존 모델 보정 자체를 지우려면 **Offset Init → 초기화 저장**을 사용한다. 빈 상태 복사를 모델 초기화나 측정 성공으로 해석하지 않는다.

NG·미측정·Masking·값 없는 항목의 실제 보정 제한과 중복 적용 방지는 유지한다.

### Offset Init / 일괄 보정

- Offset Init은 모델의 유효한 위치가 있으면 처음부터 요청할 수 있다. Cell/Head/모델 범위와 보호 Offset 정책은 유지한다. 화면에서 먼저 초기화하고 저장 확인 후 실제 모델에 반영한다.
- 일괄 보정은 비활성화된 버튼만 보여주지 않고 **눌러서 현재 적용 가능 여부를 확인**할 수 있게 한다. 새 OK 결과가 없으면 제외 이유를 안내하고 후보 생성·저장·적용 확인창은 실행하지 않는다.
- 적용 가능한 결과가 있을 때만 기존 확인창 → 검증 → 저장으로 진행한다. 버튼을 누를 수 있다는 사실이 NG·미측정의 보정 허용을 뜻하지 않는다.
- 실제 동작 중·STOP 정리 중·미저장 Offset 편집 중의 보호는 유지한다.

## 이전 미완료 작업의 자동 복원

깨끗한 최초 로딩에서는 Init이 원래 가능했다. 여러 버튼이 함께 잠기는 재현 경로는 디스크의 미완료 작업이 자동 복원되어 잔여 큐가 남는 경우였다. 사용자의 실제 실행 파일이나 checkpoint 원문을 받은 것은 아니며, 코드와 합성 checkpoint로 재현했다.

이제 시작 시 자동 복원하는 미완료 작업은 **원본 전체를 엄격 검증하고 원문 bytes를 Recovery에 보존한 뒤**, 실패/잔여 이력을 남기고 대기 상태로 시작한다. 손상된 작업을 검증 전에 제거하여 정상으로 위장하지 않는다. 백업 실패 시 원문을 덮어쓰지 않는다. 명시적으로 불러온 복구 자료와 현재 메모리에서 실행 중인 작업은 자동 폐기하지 않는다.

이미 중단된 작업에서도 명시적인 상태 복사·Init은 대상/범위를 먼저 검증한 뒤 전환할 수 있다. 잘못된 대상·사유·범위라면 이전 큐를 유지한다. 응답 없는 옛 편차는 새 복사값이나 보정값으로 재사용하지 않는다. 이미 복사한 빈 상태는 측정 시도가 응답 없이 실패했다는 이유만으로 과거 B 표시로 되살아나지 않는다.

작업 상태 복사에는 모델·Run·좌표 기준·논리 상태 변경 시각을 기록한다. 오래된 자동 파일 갱신이 방금 복사한 빈 상태를 덮어쓰지 않으며, 명시적인 새 측정은 새로운 결과로 갱신한다. 이 시각은 원측정 시각을 위조하는 값이 아니다.

같은 Shot의 다른 Beam이 보정을 저장해 공유 B가 바뀌어도, 이 점에 명시적으로 복사한 빈 상태·NG 상태가 자동으로 측정값으로 되살아나지 않는다. 실제 새 측정·새 값 복사·명시 초기화/교체·되돌리기의 의미에 따라 상태를 갱신한다. 가져온 파일의 원측정 출처도 Init/Undo 때문에 실제 카메라 원측정으로 바꾸지 않는다.

## 좌우 패널과 하단 결과표

| 위치 | 내용 |
| --- | --- |
| 중앙 | 2D 결과 지도. 표준 키보드·클릭/드래그 선택·확대/축소·현재 측정 점멸 유지 |
| 왼쪽 펼침 | 필터, 범례, 작업정보, 필터 적용 상태, 산포도, 설정, 적용 이력 |
| 오른쪽 펼침 | 공통 선택점/대표 정보, 대표값 복사, 보정 확인·실행·초기화·후보 |
| 하단 | 접을 수 있는 측정결과표와 기존 페이지 이동 |

긴 내용은 작은 페이지로 나눠 **중앙 지도와 좌우 패널의 외부 스크롤 없이** 조작한다. 대량 데이터 표·산포 통계·대상 목록의 국소 스크롤은 필요할 때 유지한다. 필수 설정 입력과 저장 버튼은 각 페이지에서 끝까지 보인다. Level 설정은 이름과 상한을 한 줄에 배치한 짧은 표로 바꿨다.

Ctrl+F는 왼쪽 검색을 열고, 새 측정 결과는 오른쪽 선택점 정보로 연결된다. 파일을 불러오기 전 작업으로 돌아가면 좌우 펼침 상태와 내부 페이지, 지도 선택·확대·산포 범위도 복원한다. 패널을 펼치는 행위는 장비를 이동시키거나 보정을 저장하지 않는다.
