Head별 ATT-출력 테이블 예제

실측값으로 변경 필요: 아래 HEAD01.csv ~ HEAD08.csv는 임의 예제입니다.
실제 장비 운전 전 각 헤드/광학 경로에서 검증한 ATT 각도별 출력(W) 실측값으로 교체해야 합니다.
현재 로더는 실측 여부를 자동 판별하지 않으며 이 예제도 일반 테이블처럼 읽습니다.
ATT Limit은 Setting > OPTION > INTERLOCK의 Attenuator Degree Min/Max SW Limit에서 변경 가능합니다.
기본 설정 0/0은 제한 비활성화가 아니라 0도만 허용합니다. 사용 전에 장비에 맞는 범위로 설정해야 합니다.
JHMI_SETTING.csv의 입력 메타데이터 MIN/MAX 0/0은 숫자 입력 범위를 제한하지 않으므로 180 또는 360 등의 값을 입력할 수 있습니다.

HEAD01.csv ~ HEAD08.csv는 동일한 예제 데이터입니다.
열: Attenuator_deg(각도, deg), Power_W(출력, W).
각 파일은 헤더 1행과 데이터 37행으로 구성됩니다.
ATT는 0 ~ 360 deg를 10 deg 간격으로, 출력은 0 ~ 36 W를 1 W 간격으로 넣었습니다.
예: 0 deg = 0 W, 10 deg = 1 W, 360 deg = 36 W.

현재 값은 임의로 만든 예제이며 실측 데이터가 아닙니다.
Manual SHAPE SCAN START에서 각 Head에 지정한 .scan의 Laser Power(W)를 해당 HEAD 테이블에서 ATT 각도로 변환합니다.
테이블 사이 값은 선형 보간하며, 출력 범위를 벗어나거나 각도가 중복되거나 출력이 단조 증가/감소하지 않으면 실행을 차단합니다.
연결된 ATT만 공통 상태 수집기가 0.5초 간격으로 읽습니다. 미연결 장치에는 조회 명령을 보내지 않습니다.
이동 명령 접수 응답으로 완료를 판단하지 않고, 명령 후 새로 수집한 스냅샷의 READY(이동 완료) 상태와 현재 각도(목표 ±0.01 deg)를 확인합니다.
선택한 모든 Head의 ATT 이동 완료를 확인한 뒤 형상 스크립트를 실행합니다. 30초 내 도착하지 못하면 실행을 차단합니다.
ATT 목표 각도는 Setting의 Attenuator Degree Min/Max SW Limit도 만족해야 합니다.
실제 장비에 맞는 측정값으로 교체해야 합니다.

Manual / PowerMeasure
- 목표 W를 둘러싼 측정값을 선형 보간해 첫 ATT 각도를 정합니다. 일치하는 실측 W가 있으면 그 각도를 사용합니다.
- 목표 W가 범위 밖이거나 파일/유효한 구간이 없거나 각도가 여러 개로 해석되면, 현재 ATT 위치에서 먼저 측정하고 탐색합니다. 첫 측정 전에 임의의 180도로 이동하지 않습니다.
- 현재 ATT 위치를 유효하게 확인할 수 없으면 해당 Head는 ERROR 처리합니다. 실장비 연결 시 공통 ATT 스냅샷으로 위치를 제공해야 합니다.
- 허용오차 내 도달하고 종료 처리가 성공한 최종 각도와 실제 평균 측정 W를 기록합니다. 목표 W를 실측값으로 기록하지 않습니다.
- 동일 각도(차이 0.000001 deg 이내)는 갱신하고 새 각도는 추가합니다. 기존 나머지 행은 유지하며 각도순으로 저장합니다.
- NG, STOP, 측정 오류, 종료 처리 실패는 테이블에 반영하지 않습니다. 저장 실패는 ERROR로 표시합니다.
- 기존 파일 갱신은 임시 파일을 통한 교체로 처리하고, 직전 파일을 HEADxx.csv.bak으로 보관합니다. 손상된 기존 파일은 자동 덮어쓰기하지 않습니다.
- 현재 Manual PowerMeasure는 시뮬레이션 전용입니다. 최초에는 원본 HEADxx.csv를 참고할 수 있지만, 측정 결과는 Config/PowerTable/Simulation/HEADxx.csv에만 저장합니다. 이후에는 해당 시뮬레이션 테이블을 참조하며 실제 보정 테이블과 혼합하지 않습니다.
- 실장비 측정 순서 연결은 보류 상태입니다. Shape Scan의 기존 엄격한 테이블 검증/이동 완료 확인 정책은 유지됩니다.
