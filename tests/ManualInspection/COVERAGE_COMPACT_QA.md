## 확인한 표시 정책

- 직접/불러온 작업 편차가 유효하면 그 값을 먼저 표시한다. 없는 점도 활성 보정행이 있으면 **측정됨 · 보정기반**으로 분류하고 저장 B를 표시 편차·Level에 사용한다.
- 명시적 0 보정행은 측정 이력/L1이며, 보정행도 실제 결과도 없는 0 기본값은 미측정이다. 미적용 후보 F는 측정 이력이나 활성색을 만들지 않는다.
- 최신 수신 오류와 기존 보정 이력을 함께 보존한다. 원측정/raw가 없는 점에 가짜 OK·Vision 숫자·native 토큰을 만들지 않는다. 보정기반 표시는 직접 보정 앵커로 승격되지 않는다.
- 지도·표·선택 요약·필터·산포는 동일한 표시 편차/Level 정책을 사용한다. 산포의 보정기반 점은 별도 수를 제공하며, 원측정 보기에는 B를 가짜 raw로 넣지 않는다.
- CSV는 기존 WORK/ORIGINAL/BASE/RAW 열을 유지하고 `MEASUREMENT_HISTORY`, `MEASUREMENT_BASIS`, `DISPLAY_DX_DESIGN_UM`, `DISPLAY_DY_DESIGN_UM`, `MEASUREMENT_LEVEL`을 추가한다.

## 실제 화면과 입력 검증

Light/Dark에서 각각 1480×900, 1120×720, 1120×560의 가용 View를 렌더했다. 기본 결과표·산포·좌표/출처·대표/보정/설정을 접은 상태에서 좌우 ScrollableHeight가 0이고, 지도 부모 Border의 client height가 지도 실제 높이보다 작지 않으며, 전체 Cell 보기의 3 Cell·2 Head·240개 표시 슬롯이 모두 지도 영역 안에 들어오는지 검사했다. 560은 상위 Correction 메뉴·탭에 공간을 쓰고 남은 화면을 가정한 값이다.

처음에는 ScrollableHeight와 지도 ActualHeight만 보면 통과하지만 부모 Border가 지도를 자르는 문제가 있었다. 독립 PNG 검토로 발견해 부모 client 높이와 전체 hit-slot 범위 검사를 추가하고 수정 후 재실행했다. 단순히 스크롤을 숨겨 지도를 잘라내는 상태를 합격으로 처리하지 않았다.

오른쪽 선택점 측정/다른 동작/측정·출처 상세와 Settings의 현재 위치 측정 버튼은 삭제됐다. 점 우클릭은 이동 3종 + 현재 위치 한 점 측정 + 측정·출처 상세를 제공한다. 현재 위치 측정/상세는 다중 선택 중에도 포커스 한 점에 연결되고, 측정 확인 취소는 요청을 보내지 않는다. 조회 전용에서는 이동·측정이 막히고 상세 조회는 가능하다. STOP은 확인창 없이 즉시 요청된다.
